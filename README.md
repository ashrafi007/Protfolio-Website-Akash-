# Intazar Akash — Model Portfolio

Static site. No build step.

## Run locally
```
python -m http.server 8000
```
Open http://localhost:8000

## Before going live
Edit `config.js` with your email, WhatsApp number and Instagram handle.

## Deploy (free)
**Netlify Drop:** go to app.netlify.com/drop and drag this whole folder in (the `source/` folder can be left out). Rename the site under Site settings.

**GitHub Pages:** push to a public repo, then Settings → Pages → deploy from `main` / root. `source/` is gitignored.

**Vercel:** `npx vercel` from this folder, accept defaults.

## Share
- Instagram: Edit profile → Links → Add external link → paste the site URL.
- Email: paste the link and attach `assets/Intazar-Akash-CompCard-2026.pdf`.
